      Optimal Transport

      Optimal transport is a method for computing the most efficient plan, and its total cost, for transporting cargo from point cloud A to point cloud B.

      For example, suppose we have points xi,yjx_i, y_jxi​,yj​, where xix_ixi​ has weight ai,yja_i, y_jai​,yj​ has weight bjb_jbj​. With the cost C(xi,yj)=∥xi−yj∥2C(x_i,y_j) = \|x_i - y_j\|_2C(xi​,yj​)=∥xi​−yj​∥2​, optimal transport asks how to move xix_ixi​ to yjy_jyj​ so that the total cost is as small as possible.

      Optimal Transport Between Probability Distributions

      As an example, consider the optimal transport problem between the following probability distributions a and b.

      a = np.array([0.2, 0.5, 0.2, 0.1])
b = np.array([0.3, 0.3, 0.4, 0.0])
C = np.array([
    [0, 2, 2, 2],
    [2, 0, 1, 2],
    [2, 1, 0, 2],
    [2, 2, 2, 0]]
) # C[i][j]: cost of transporting one unit of mass from i to j

      Given the probability distributions a and b and the cost function C(i,j) above, we treat the values aia_iai​, bjb_jbj​ as amounts of sand and consider moving the sand piles of a in the optimal way so that the distribution of a matches the distribution of b.

      Solving the optimal transport problem with the Sinkhorn algorithm gives the transport matrix P shown below.

      In the figure, the y-axis corresponds to the indices of a and the x-axis to the indices of b. PijP_{ij}Pij​ represents how much of the sand at aia_iai​ is transported to bjb_jbj​.

      Let’s look at it in more detail.

      All of the sand at a0a_0a0​ is transported to b0b_0b0​, the entry of b with the lowest transport cost.

      Most of the sand at a1a_1a1​ goes to b1b_1b1​, and the remaining sand is transported to b0,b2b_0, b_2b0​,b2​.

      All of the sand at a2a_2a2​ is transported to b2b_2b2​.

      The sand at a3a_3a3​ is transported to b0,b2b_0, b_2b0​,b2​.

      By computing the optimal transport cost in this way, we can compute a distance between probability distributions.

      Applications of Optimal Transport

      • Measuring the distance between probability distributions a and b
      • Measuring the distance between point clouds a and b.
      • Measuring the distance between sentences a and b (Word Mover’s Distance (WMD)): treat the words in each sentence as vectors and perform optimal transport between the two sets of vectors

      Formulating the Optimal Transport Problem

      Given points xi,yjx_i, y_jxi​,yj​, the weight aia_iai​ of xix_ixi​, the weight bjb_jbj​ of yjy_jyj​, the cost C(xi,yj)C(x_i,y_j)C(xi​,yj​) of transporting one unit of mass from xix_ixi​ to yjy_jyj​, and the transported amount PijP_{ij}Pij​, the optimal transport problem is formulated as the following linear optimization problem.

      OT(a,b,C):=min⁡P∈Rn∗m∑in∑jmC(xi,yj)Pijs.t.Pij≥0∑jmPij=ai∑inPij=bj\begin{gathered} OT(a,b,C) := \underset{P\in R^{n*m}}{\min} \sum^n_i \sum^m_j C(x_i,y_j)P_{ij}\\ s.t. \\ P_{ij} \geq 0 \\ \sum^m_j P_{ij} = \bf{a}_i \\ \sum^n_i P_{ij} = \bf{b}_j \end{gathered}OT(a,b,C):=P∈Rn∗mmin​i∑n​j∑m​C(xi​,yj​)Pij​s.t.Pij​≥0j∑m​Pij​=ai​i∑n​Pij​=bj​​

      The optimal transport problem is to find the optimal transport cost by varying the entries of PPP subject to the three constraints at the bottom.

      The optimal solution of this problem is the optimal transport plan PijP_{ij}Pij​, and the optimal value is the optimal transport cost d=∑in∑jmC(xi,yj)Pijd = \sum^n_i \sum^m_j C(x_i,y_j)P_{ij}d=∑in​∑jm​C(xi​,yj​)Pij​.

      The last two constraints can also be written as follows.

      1m∈Rm,1n∈RnP1m=aP⊤1n=b\begin{gathered} 1_m \in R^m, 1_n \in R^n\\ P1_m = \bf{a} \\ P^\top 1_n = \bf{b} \end{gathered}1m​∈Rm,1n​∈RnP1m​=aP⊤1n​=b​

      This can be seen from

      (P1m)i=∑kmPik=ai(P⊤1n)j=∑knPjk⊤=∑knPkj=bj\begin{gathered} (P1_m)_{i} = \sum^m_k P_{ik} = \bf{a}_i\\ (P^\top 1_n)_{j} = \sum^n_k P^\top_{jk} = \sum^n_k P_{kj} = \bf{b}_j \end{gathered}(P1m​)i​=k∑m​Pik​=ai​(P⊤1n​)j​=k∑n​Pjk⊤​=k∑n​Pkj​=bj​​

      These constraints mean that the row sums of P are ai,a_i,ai​, and the column sums are bjb_jbj​, which enforces conservation of the transported mass.

      Wasserstein Distance

      A special case of the optimal transport cost.

      When the cost CijC_{ij}Cij​ is a distance between points (one that satisfies the axioms of a metric), the optimal transport cost d(a,b)d(\bf{a}, \bf{b})d(a,b) satisfies the axioms of a metric.

      In this way, when the optimal transport cost satisfies special conditions, it becomes a distance, called the Wasserstein distance.

      Optimal Transport with Entropic Regularization

      OTϵ(a,b,C):=min⁡P∈Rn∗m∑ijPijCij−ϵH(P)H(P):=−∑ijPij(log⁡Pij−1)\begin{gathered} OT_\epsilon(a,b,C) := \underset{P\in R^{n*m}}{\min} \sum_{ij} P_{ij} C_{ij} - \epsilon H(P)\\ H(P) := - \sum_{ij}P_{ij}(\log{P_{ij}} - 1) \end{gathered}OTϵ​(a,b,C):=P∈Rn∗mmin​ij∑​Pij​Cij​−ϵH(P)H(P):=−ij∑​Pij​(logPij​−1)​

      We add the entropic regularization term −ϵH(P)-\epsilon H(P)−ϵH(P), changing the problem to be solved.

      This makes the problem easier to optimize, and it can be solved by iterative matrix computations with the Sinkhorn algorithm.

      This also makes OTϵ(a,b,C)OT_{\epsilon} (a,b, C)OTϵ​(a,b,C) differentiable with respect to its inputs.

      The Sinkhorn Algorithm

      The Sinkhorn algorithm is an algorithm for solving the entropy-regularized optimal transport problem.

      An implementation in JAX is shown below.

      def Sinkhorn(a: jnp.ndarray, b: jnp.ndarray, x: jnp.ndarray, y: jnp.ndarray
                            , eps: float)->(float, jnp.ndarray):
    C = jnp.zeros((n, m)) # Cost Matrix
    for i in range(n):
        for j in range(m):
            C = C.at[i,j].set(jnp.linalg.norm(x[i] - y[j]))
    K = jnp.exp(- C / eps) # Gibbs kernel
    u = jnp.ones(n)
    v = jnp.ones(m)
    for i in range(100):
        v = v.at[:].set(b / (K.T @ u))
        u = u.at[:].set(a / (K @ v))
    P = u.reshape(n, 1) * K * v.reshape(1, m)
    d = (C * P).sum()
    return d, P

      Since the Sinkhorn algorithm consists only of differentiable operations, we can obtain gradients with automatic differentiation.

      Because it is differentiable, we can, for example, move point cloud A toward point cloud B with gradient descent.

      Specifically, we take the positions X of A as parameters and the optimal transport cost d as the cost function L, compute dL/dXdL/dXdL/dX, and repeat X←X−ϵ∗dL/dXX ← X - \epsilon * dL/dXX←X−ϵ∗dL/dX to move point cloud A toward point cloud B.

      With JAX, gradient descent can be implemented as follows.

      grad_x = jax.grad(lambda x: Sinkhorn(a, b, x, y, eps)[0])(x)
x -= 0.1 * grad_x

      Rather than each point moving to its nearest neighbor, the points move while taking the overall relationships into account, as if making way for one another.

      Wasserstein Barycenter

      Given multiple probability distributions, optimal transport gives a distribution that serves as their barycenter.

      A generalization of k-means clustering.

      As an application, in ensemble learning it can be used to combine the predictive distributions output by multiple models into one.
